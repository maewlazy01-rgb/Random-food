# 🍜 Random food — Mobile App V4

เว็บไซต์ต้นแบบสำหรับค้นหาเมนูอาหาร สุ่มเมนูตามงบประมาณและความชอบ เลือกอาหารใส่ตะกร้า และทดลองสั่งอาหารผ่านหน้าจอมือถือหรือคอมพิวเตอร์

## ✨ ฟีเจอร์ในต้นแบบ

- 🎲 สุ่มเมนูตามงบประมาณ ประเภทอาหาร และระดับความเผ็ด
- 🔎 ค้นหาและกรองเมนูอาหาร
- ❤️ บันทึกรายการโปรดระหว่างใช้งาน
- 🛒 เพิ่ม/ลดจำนวนอาหารในตะกร้าและคำนวณยอดรวม
- 🏪 แสดงร้านอาหารตัวอย่าง
- 🧾 ทดลองสั่งอาหารและดูประวัติออเดอร์
- 👤 หน้าสมาชิกและเข้าสู่ระบบแบบจำลอง
- 📝 แบบฟอร์มรายงานปัญหาแบบจำลอง
- 📱 รองรับหน้าจอมือถือ และมีไฟล์ PWA สำหรับการติดตั้งบนอุปกรณ์ที่รองรับ

## 🚀 เปิดใช้งานผ่าน GitHub Pages

1. เข้าแท็บ **Settings** ของ Repository
2. เลือก **Pages** ในเมนูด้านซ้าย
3. ในส่วน **Build and deployment** เลือก **Deploy from a branch**
4. เลือก Branch เป็น `main` และโฟลเดอร์เป็น `/(root)`
5. กด **Save** แล้วรอให้ GitHub Pages เผยแพร่เว็บไซต์

เมื่อเผยแพร่สำเร็จ เว็บไซต์จะอยู่ที่:

https://maewlazy01-rgb.github.io/Random-food/

## 📁 ไฟล์หลัก

- `index.html` — หน้าเว็บและโค้ดการทำงานของต้นแบบ
- `manifest.webmanifest` — ข้อมูลสำหรับ PWA
- `icon.svg` — ไอคอนแอป
- `sw.js` — Service Worker สำหรับแคชไฟล์ที่กำหนด

## ⚠️ หมายเหตุ

โปรเจกต์นี้เป็น **ต้นแบบสำหรับสาธิต** ข้อมูลร้านอาหาร ราคา ค่าส่ง คูปอง การเข้าสู่ระบบ การรายงานปัญหา และคำสั่งซื้อเป็นข้อมูลจำลอง ยังไม่มีระบบหลังบ้านหรือการชำระเงินจริง และข้อมูลบางอย่างจะไม่ถูกบันทึกถาวร อย่าใส่รหัสผ่านจริงในแบบฟอร์มสมาชิกของต้นแบบนี้

ภาพอาหารบางส่วนโหลดจาก URL ภายนอก จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อแสดงภาพเหล่านั้น
